# 패턴 빠른 색인

이 파일은 `session-skill` 빠른 운영 모드의 기본 판단 자료다.  
세션 전·중 1차 분류는 이 색인만 읽고 후보 영역·패턴을 1~2개까지 좁힌 뒤 바로 출력한다.

## 사용 원칙

1. 빠른 운영 모드에서는 이 파일만 읽고 답한다.
2. `patterns/pattern-01.md`~`patterns/pattern-30.md`는 정밀 모드용이다. 사용자가 정밀·상세·내부 사전 확인을 요청했거나 후보 충돌·Fallback 판단이 어려울 때만 해당 후보 파일 1~2개를 읽는다.
3. 후보가 3개를 넘으면 패턴 파일 전체 탐색 대신 Fallback A/B/D 판단을 먼저 검토한다.
4. 최종 출력은 12줄 이내로 줄이고, 대표 사례·내부 사전 항목은 출력하지 않는다.
