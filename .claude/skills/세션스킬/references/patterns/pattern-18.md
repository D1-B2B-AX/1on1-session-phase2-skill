## 패턴 18. DIKW 정보화

> **영역**: 8. 외부 표준 합성 · **빈도**: ★ · **흡수**: #16 DIKW 정보화

### 기본 분류
- 영역: 8. 외부 표준 합성
- 패턴: 18. DIKW 정보화
- 실행 양식: raw→시그널→점수 변환

### 한 줄 기준

raw 데이터는 많지만 의사결정 가능한 정보로 변환되지 않을 때 적용한다.

### 적용 신호

- 슬랙·메일·메모·시트·DB 같은 raw 데이터는 많다.
- 사용자가 데이터를 직접 보지만 판단 로직이 정리되지 않는다.
- Data → Information 변환이 끊겨 있다.
- 점수·시그널·카테고리로 바꾸면 판단 가능성이 생긴다.
- 결손 처리 기준이 필요하다.

### 비적용 신호

- raw가 이미 판단 가능한 시그널이나 점수로 변환되어 있다.
- 판단 질문이 없어 무엇을 정보화할지 정할 수 없다.
- 없는 데이터를 LLM 추정으로 메우려는 상황이다.
- 문제의 핵심이 정보 변환이 아니라 외부 표준과 현장 기준 합성이다.

### 필요한 입력값

- raw 데이터(슬랙·메일·메모·시트·DB) / 판단 질문 / 시그널 후보 / 결손 처리 기준 / 점수·티어 구조 후보

### 판단 기준

- 사용자가 데이터를 직접 보지만 판단 로직이 정리되지 않는다.
- Data → Information 변환이 끊겨 있다.
- 점수·시그널·카테고리로 바꾸면 판단 가능성이 생긴다.
- 없는 데이터를 만들어내면 안 된다.

### 추천 액션

- 실행 시점: raw는 있으나 의사결정에 바로 쓰이지 못하는 상황이 확인된 직후
- 실행 주체: 세션 담당자와 LD
- 액션 내용: 판단 질문 먼저 작성·raw 데이터에서 어떤 시그널 추출할지 정함. 시그널을 점수 매트릭스·티어 구조로 연결·결손 데이터는 추정 X·결손으로 표기
- 완료 기준: raw→시그널 변환표·시그널→점수 매트릭스·점수→티어 구조·결손 처리 원칙 정리

### 주의사항

- 오분류 위험: 없는 데이터를 만들어내면 정보화가 아니라 추정
- 헷갈리는 패턴: 외부 frame + LD 직관 합성(패턴 17) — DIKW 정보화는 데이터를 판단 가능한 정보로 바꾸는 단계. 또 LD 입력값 비교 검증(패턴 8) — DIKW는 raw 데이터를 시그널·점수로 변환하는 영역·LD 입력값 비교는 기존 LD 판단값과 LLM 결과를 비교하는 grounding 양식
- 쓰면 안 되는 조건: 판단 질문 없이 raw를 점수화하려는 경우
- 추가 주의: 결손은 결손으로 표기·LLM 추정으로 메우지 않음

### 대표 사례

- 이현진 딜판단: 딜 금액·파이프라인 단계·마감 임박도는 DIKW 조건 충족·고객 가치·소통 활동도·거래 의지는 결손 있음. 7기준 정보화 매트릭스와 T1/T2/T3 티어로 변환

### 정보 부족 시 확인 질문

- 지금 raw 데이터는 어떤 파일이나 채널에 있나요?
- 이 데이터로 답하려는 판단 질문은 무엇인가요?
- raw에서 뽑을 수 있는 시그널 후보는 무엇인가요?
- 시그널을 점수나 티어로 바꾸는 기준이 있나요?
- 결손 데이터는 어떻게 표시할 건가요?
