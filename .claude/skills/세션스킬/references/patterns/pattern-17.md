## 패턴 17. 외부 frame + LD 직관 합성

> **영역**: 8. 외부 표준 합성 · **빈도**: ★ · **흡수**: #15 외부 표준+현장성 합성

### 기본 분류
- 영역: 8. 외부 표준 합성
- 패턴: 17. 외부 frame + LD 직관 합성
- 실행 양식: 외부 표준과 현장 입력 합성

### 한 줄 기준

판단 기준이 필요하지만 LD 직관만으로는 약하고, 외부 표준만으로는 현장에 안 맞을 때 적용한다.

### 적용 신호

- 판단 로직이 정리되지 않았다.
- 외부 프레임워크는 있지만 조직 맥락과 다를 수 있다.
- 현장 LD의 언어와 행동 지표가 필요하다.
- Won/Lost 실제 사례나 실증자 작업 패턴을 볼 수 있다.

### 비적용 신호

- 외부 표준만으로 충분히 판단 가능한 업무다.
- 현장 LD 의견이나 실제 사례를 확보할 수 없다.
- 판단 기준보다 데이터 변환이나 검증 방식이 먼저 필요한 상황이다.
- 현장 의견만 있고 객관 지표를 붙일 수 없다.

### 필요한 입력값

- 외부 프레임워크(BANT·CHAMP·MEDDPICC 등) / 현장 LD 의견 / 실증자 작업 패턴 / Won/Lost 실제 사례 / 기준별 데이터 소스

### 판단 기준

- 외부 표준은 있지만 조직 맥락과 다를 수 있다.
- 현장 LD의 언어와 행동 지표가 필요하다.
- 외부 표준만 가져오면 현장성 떨어짐 / 현장 의견만 쓰면 객관 지표 약해짐.

### 추천 액션

- 실행 시점: 판단 매트릭스가 필요하지만 기준이 약하거나 현장성이 부족할 때
- 실행 주체: 세션 담당자와 LD
- 액션 내용: 외부 프레임워크별 기준 비교·현장 LD 의견·실증자 작업 패턴·Won/Lost 사례에서 현장 언어·행동 지표 추출. 두 입력 합쳐 case 전용 판단 매트릭스·기준별 데이터 소스 만듦
- 완료 기준: 외부 표준·현장 input·case 전용 판단 매트릭스·기준별 가중치와 데이터 소스 정리

### 주의사항

- 오분류 위험: 외부 표준을 그대로 가져오면 현장성 떨어짐
- 헷갈리는 패턴: DIKW 정보화(패턴 18) — 외부 표준+현장성 합성은 판단 기준을 만드는 단계, DIKW 정보화는 raw를 시그널·점수로 변환하는 단계
- 쓰면 안 되는 조건: 현장 의견·실제 사례 없이 외부 표준만 붙이는 경우
- 추가 주의: 현장 의견만 쓰면 객관 지표 약해짐

### 대표 사례

- 이현진 딜판단: 글로벌 B2B 영업 프레임워크 리서치와 2팀 파트장·노을 LD 의견·김민선 작업 패턴·Won/Lost 역산을 합성해 7기준 매트릭스 작성

### 정보 부족 시 확인 질문

- 참고할 외부 프레임워크가 있나요?
- 현장 LD가 실제로 쓰는 판단 언어는 무엇인가요?
- Won/Lost 같은 실제 사례를 볼 수 있나요?
- 실증자가 실제로 어떤 순서로 판단하는지 확인했나요?
- 외부 기준과 현장 기준이 충돌하는 항목은 무엇인가요?
