## §2. 영역 15개 — 상세 정의 (3 양식)

### 영역 1. AI 역할 축소 (★★★)
- **압축**: AI 통째 처리 X·Stage·HITL·셀 매트릭스·역산 설계로 역할 분담
- **쉽게**: AI에게 모든 걸 맡기지 않고 *룰·LLM·사람*으로 단계 나누거나 역할 좁히는 양식
- **비유**: 회사에서 한 명에게 모든 업무 던지지 않고 *기획·실무·검수* 단계 나누는 양식

### 영역 2. 코드·LLM 분리 (★★)
- **압축**: 같은 입력=같은 출력 영역은 코드·문맥 판단 영역은 LLM 분리 접합
- **쉽게**: 숫자 계산은 코드에 맡기고·문장 해석은 AI에 맡기는 양식
- **비유**: 계산기로 풀 문제와 사람이 판단할 문제를 섞지 않는 양식

### 영역 3. LD 자립 빌더 (★★)
- **압축**: LD가 도구 사용자에서 도구 진화시키는 사람으로 단계 학습
- **쉽게**: LD가 *처음엔 받아쓰기·다음엔 같이 만들기·끝엔 혼자 만들기*로 단계 학습
- **비유**: 운전 면허처럼 *조수석·연습·혼자 운전* 단계로 진화

### 영역 4. 본질 anchor (★)
- **압축**: 처음 페인·솔루션 흔들림 방지·페인 재정의 컨펌 반복
- **쉽게**: 처음 잡은 *왜 만들지·뭘 만들지*를 도구가 커져도 잊지 않게 박는 양식
- **비유**: 등산할 때 정상 위치(북극성)를 잃지 않게 계속 확인하는 양식

### 영역 5. 자동화 한계 인정 (★★)
- **압축**: 자동화하면 손해인 영역 인정·룰 특정 데이터 over-fit 검증
- **쉽게**: 모든 일을 AI가 잘하지 않는다는 걸 인정하고·*사람이 봐야 할 영역*은 남기는 양식
- **비유**: 빨래는 세탁기·요리는 사람처럼 *기계가 잘하는 영역과 사람이 잘하는 영역* 나누는 양식

### 영역 6. diff 룰 발견 (★★)
- **압축**: AI 초안·사람 정답 차이에서 사람 암묵지를 룰로 번역
- **쉽게**: AI가 만든 결과랑 사람이 만든 결과를 비교해서·*사람이 무엇을 다르게 했는지* 규칙으로 뽑는 양식
- **비유**: 신입 직원이 만든 보고서와 베테랑이 만든 보고서 비교해서 *베테랑 노하우* 추출

### 영역 7. 학습·구현 하네스 (★)
- **압축**: 머릿속·문서 흩어진 도메인 지식을 공통 문서·하네스로 명시
- **쉽게**: AI와 사람이 같은 기준으로 일하게 *공통 사전*을 미리 만드는 양식
- **비유**: 두 명이 같은 게임 규칙으로 플레이하게 *규칙북*을 같이 보는 양식

### 영역 8. 외부 표준 합성 (★)
- **압축**: LD 직관 + 외부 frame 합성·현장성 정합
- **쉽게**: *교과서 이론*과 *현장 경험*을 합쳐서 우리 회사 맞춤 기준 만드는 양식
- **비유**: 요리책 레시피에 *우리 집 입맛*을 더해서 우리 맞춤 레시피 만드는 양식

### 영역 9. 데이터 흐름 점검 (★)
- **압축**: *도구 이상*처럼 보여도 실제 데이터 누락·소스 결정 영역 점검
- **쉽게**: *Gmail이 안 되네*가 아니라 *어디 단계에서 데이터가 빠졌나* 보는 양식
- **비유**: 수도꼭지에서 물이 안 나올 때 *수도꼭지*만 보지 말고 *수도관·계량기·필터* 차례로 보는 양식

### 영역 10. Validation 분기 (★★★)
- **압축**: 사용·결과 효과·검증 주인 부재 case별 검증 양식 선택
- **쉽게**: *도구 만들었으면 검증해야 하는데·case마다 검증 양식이 다르다*는 양식
- **비유**: 시험 종류(객관식·서술식·면접·실기)마다 채점 방식이 다른 양식

### 영역 11. 권한 벽 우회 (★)
- **압축**: 조직 정책·권한 정공법 막힘 영역 우회 경로 발견
- **쉽게**: 회사 정책 때문에 안 되는 게 있을 때 *허용 가능한 다른 길*을 찾는 양식
- **비유**: 본 도로가 막혔을 때 *허용된 우회 도로*를 찾는 양식 (불법 길 X)

### 영역 12. 수신자별 액션 카드 (★)
- **압축**: 분석 결과를 *누구에게 뭘 요청할지*로 양식화
- **쉽게**: 보고서가 *그래서 뭘 해야 하지?*에서 멈추지 않게·*누구한테 뭘 요청하라*까지 명시
- **비유**: 의사가 진단 후 *환자에게 약 처방·간호사에게 검사 지시·가족에게 안내* 따로 주는 양식

### 영역 13. 계획 검토 분산 (★)
- **압축**: 큰 계획 한 사람 정합성 검토 어려울 때 분산 양식
- **쉽게**: 큰 계획을 *한 명이 다 보지 말고 여러 명이 나눠 보기*로 결함 빨리 찾는 양식
- **비유**: 큰 책 원고를 한 명이 다 교정 X·여러 편집자가 분야별로 나눠 교정하는 양식

### 영역 14. 룰 폭 균형 (★)
- **압축**: 룰 타이트 시 본질 충돌·넓을 시 결함 통과 균형점
- **쉽게**: 규칙을 너무 빡빡하게 잡으면 정상도 막히고·너무 넓게 잡으면 결함도 통과·중간점 찾는 양식
- **비유**: 보안 검색대 — 너무 엄격하면 정상 승객도 걸리고·너무 느슨하면 위험물도 통과

### 영역 15. 구현형 형식지 추출 (★)
- **압축**: 문서 X·코드/화면/AI 대화에 박힌 반복 양식 발견·형식화
- **쉽게**: *문서로 안 박혀있어도 코드·화면·AI 대화 안에 이미 박힌 규칙*을 끄집어내는 양식
- **비유**: 할머니 손맛 레시피 — 종이엔 없지만 *손이 외운* 양식을 글로 옮기는 양식

#### 패턴 1. Stage·HITL 도구 분담 (★★★)
- **압축**: 룰·LLM·사람 영역 3 Stage 분리 + HITL 자리 유지
- **쉽게**: AI 작업을 *고정 룰 단계·AI 판단 단계·사람 검수 단계* 3 단계로 나누는 양식
- **비유**: 공장에서 *컨베이어 벨트(룰)·로봇 팔(AI)·QC 검수원(사람)* 3 단계 라인 분리
- **헷갈리는 패턴**: 패턴 7 (코드·LLM 분리)는 *정량·정성 분리*·본 패턴은 *룰·LLM·사람 3 단계*

#### 패턴 2. 반복 운영 좁힘 (★★★)
- **압축**: 셀 매트릭스 대상 분기 + 액티브 게이트 시점 필터
- **쉽게**: 전체 대상 다 처리하지 말고 *오늘 봐야 할 것*만 좁히는 양식
- **비유**: 학교 출석부 — 전교생 다 부르지 않고 *오늘 결석한 학생만* 따로 표시
- **헷갈리는 패턴**: 패턴 1의 AI 역할 좁히기 갈래는 *LLM 작업 범위 좁힘*·본 패턴은 *처리 대상·시점 좁힘*

#### 패턴 3. Core·Shell 분리 (★★)
- **압축**: 사람 판단 Core + AI 구현 Shell 양식
- **쉽게**: *뭘 만들지·어떤 데이터가 맞는지·완성 기준*은 사람이·*어떻게 코딩할지*는 AI가
- **비유**: 건축 — 설계도(사람) vs 실제 시공(AI 도구)
- **헷갈리는 패턴**: 패턴 7 (코드·LLM 분리)는 *정량 vs 정성*·본 패턴은 *사람 판단 vs AI 구현*

#### 패턴 4. Phase 작업 범위 구분 (★)
- **압축**: 자동 반영 가능 영역 vs LD 자연어 운영 영역 분리
- **쉽게**: *도구가 잘하는 표준 영역*과 *사람이 자연어로 운영해야 하는 예외 영역*을 처음부터 나누는 양식
- **비유**: 패스트푸드점 — 메뉴는 표준화·고객 요청 변형은 점원이 자연어로 처리
- **헷갈리는 패턴**: 패턴 13 (수동 영역 보존)은 *특정 항목 자동화 X*·본 패턴은 *전체 업무 영역 경계 설계*

#### 패턴 5. 콘텐츠 역산 설계 (★)
- **압축**: 다단계 콘텐츠를 가장 구체적 단위부터 거꾸로 설계
- **쉽게**: *큰 구조부터 만들지 말고·가장 작고 구체적인 단위부터 만들면 큰 구조가 자연스럽게 나오는* 양식
- **비유**: 영화 만들기 — 큰 줄거리부터 X·가장 인상적인 한 장면부터 정하면 전체 흐름이 보임
- **헷갈리는 패턴**: 패턴 4 (Phase 작업 범위)와 다름·본 패턴은 *콘텐츠 구조 도출 순서*

#### 패턴 6. AI 처리 chain 분담 (★)
- **압축**: 여러 AI 스킬 순차 실행으로 한 LLM 부담 분담
- **쉽게**: 한 AI한테 다 시키지 말고·*여러 AI 스킬을 순서대로* 연결해서 처리
- **비유**: 공장 라인 — 한 사람이 다 만들지 않고 *조립·도색·검사* 단계별 담당자
- **헷갈리는 패턴**: 패턴 30 (LLM 동적 도구 호출)은 *AI가 상황 보고 도구 선택*·본 패턴은 *고정 순서 chain*

#### 패턴 28. AI 자기 한계 신호 (★★) [260520 추가]
- **압축**: AI 출력에 확신도·정보 부족 메타 표시
- **쉽게**: AI가 답을 낼 때 *"이건 잘 모르겠다·정보 부족·추정 포함"* 같이 표시해서 사용자가 어디를 확인해야 할지 알게 하는 양식
- **비유**: 학생이 시험 답안에 *확신함·약간 헷갈림·찍었음* 표시 같이 적기
- **헷갈리는 패턴**: 패턴 1의 HITL 갈래는 *사람 개입 자리 설계*·본 패턴은 *AI가 자기 한계 메타 출력*

#### 패턴 29. 프롬프트 반복 개선 (★★) [260520 추가]
- **압축**: 프롬프트 작은 변경·파라미터 조정 반복으로 결과 개선
- **쉽게**: 프롬프트를 *한 번에 완벽하게* 만들 수 없고·*작은 변경 반복*으로 결과를 다듬는 양식. 모델·답변 길이 같은 설정값도 같이 조정
- **비유**: 요리 — 한 번에 간을 맞추지 않고 *간 보면서 조금씩 양념 조정*
- **헷갈리는 패턴**: 패턴 14 (AI 초안·정답 차이)는 *출력 차이에서 룰 도출*·본 패턴은 *입력 지시 자체 조정*

#### 패턴 30. LLM 동적 도구 호출 (★★) [260520 추가]
- **압축**: LLM이 상황 보고 외부 도구를 동적으로 골라 호출 (ReAct 등)
- **쉽게**: AI가 일하다가 *"이 작업엔 계산기·여기는 검색·여기는 DB"* 라고 스스로 판단해서 외부 도구 골라 쓰는 양식
- **비유**: 사람 어시스턴트에게 *"필요할 때 알아서 검색·계산·전화 걸어"* 권한 위임
- **헷갈리는 패턴**: 패턴 6 (AI 처리 chain 분담)은 *고정 순서*·본 패턴은 *동적 선택*

### 영역 2 · 코드·LLM 분리 (2 패턴)

#### 패턴 7. 결정론 계산 코드화 (★★)
- **압축**: 정량 계산·집계·비율은 코드 / 정성 판단은 LLM
- **쉽게**: 숫자 계산은 코드에·문장 해석은 AI에 맡기는 양식. 같은 데이터 두 번 돌려도 숫자가 흔들리면 위험 신호
- **비유**: 계산기로 풀어야 하는 문제를 ChatGPT에게 시키면 매번 답이 미세하게 달라지는 양식
- **헷갈리는 패턴**: 패턴 1 (Stage·HITL)은 *룰·LLM·사람 단계 분담*·본 패턴은 *정량·정성 역할 분리*

#### 패턴 8. LD 입력값 비교 검증 (★)
- **압축**: LLM 판단을 LD 이미 입력값과 비교·비결정성 감소
- **쉽게**: AI가 추측한 답을 *LD가 이미 입력한 값*과 비교해서 *AI 판단이 맞는지* 점검
- **비유**: 학생 답안과 *베테랑 선배 답안*을 비교해서 답안 흐름이 비슷한지 보는 양식
- **헷갈리는 패턴**: 패턴 18 (DIKW 정보화)는 *raw → 정보 변환*·본 패턴은 *기존 LD 값과 LLM 값 비교*

- **헷갈리는 패턴**: 패턴 6 (AI 처리 chain 분담)은 *AI 단계 분담*·본 패턴은 *LD 역할 변화*

- **비유**: 시험에서 *맞춘 거 같다* 느낌 X·*답안지와 직접 비교*해서 맞춘 영역
