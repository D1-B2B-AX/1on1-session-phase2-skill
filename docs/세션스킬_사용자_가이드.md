# 세션스킬 사용자 가이드 (세션 담당자용)

> **대상**: AX팀 세션 담당자 (코치·진행자)
> **본질**: 1:1 AX 세션 전·중·후 SKILL 진입·결과 해석·회고 안내 흐름 가이드

---

## 1. SKILL이 하는 일

세션 대상자 (LD·OM·B2B 영업·마케팅 등)의 case를 받아 다음 5섹션으로 출력:

1. **분류 결과**: 현재 단계 (3-1~3-5)·영역 (15개 중)·패턴 (30개 중)·실행 양식
2. **분류 근거**: 왜 이 분류인지 (자연어 본문 + case 본문 직접 인용)
3. **다음 액션**: 실행 설계 요약 (AX 핵심 판단·만들 것·입력·출력·적정 작동 기준) + 지금 할 일 + 후속 영역
4. **주의사항**: 오분류 위험·헷갈리는 패턴 분리·다음 단계 진입 전 점검 조건
5. **회고 안내**: 4 질문 자유 본문 답변 → SKILL이 `feedback/sessions_YYYYMM.md`에 자동 누적

---

## 2. 진입 방법

### 2-1. 트리거

새 Claude Code 세션에서:
```
/세션스킬
```

### 2-2. 입력 양식 (4 영역·자유 본문)

SKILL이 4 영역 입력 안내를 박음. 자유 양식으로 case 본문 박음:

| 영역 | 본질 |
|---|---|
| 업무 유형 | 세션 대상자가 하는 일·어떤 영역인지 |
| 현재 해결 방식 | 지금 어떻게 처리 중인지 (수작업·도구·자동화 단계) |
| 시도한 도구·결과물 | 프롬프트·코드·산출물·검증 양식·비교용 정답본 |
| 세션 대상자 발화 | 본인 표현 그대로·막힌 지점·고민 표현 |

→ 2개 이상 비면 Fallback A (입력 부족)로 빠짐·가능한 만큼 채워야 분류 정확도 ↑

### 2-3. 출력 받기

SKILL이 5섹션 표준 양식으로 출력. 세션 담당자는 출력 본문을 *그대로 세션 대상자와 공유* 가능 또는 *핵심만 발췌해서 설명* 가능.

---

## 3. 결과 해석 가이드

### 3-1. 분류 결과 영역

```
- 현재 단계 추정: 3-X (단계명) — 1줄 정의
- 영역: 영역 N (영역명) — 1줄 정의
- 패턴: 주 패턴 N (패턴명) + 보조 패턴 N (필요 시) + 후속 패턴 N (필요 시)
- 실행 양식: 양식명·실제 적용 방식
```

**해석 잣대**:
- *동시 진행* 표기 (예: *3-2·3-3 동시 진행*) — 두 단계 신호가 섞인 영역·다음 액션이 두 단계 모두 다룸
- *결합형* 표기 (주 + 보조) — 두 패턴이 서로 다른 측면 분담·둘 다 적용해야 본질 보존
- *(추정)*·*(LD 확인 필요)* 표기 — case 본문 신호 부족 영역·세션 대상자 직접 확인 필요

### 3-2. 다음 액션 영역 (실행 설계 요약 5 항목)

```
실행 설계 요약 (가이드 수준·세부 실행안 X)
- AX 핵심 판단: ...
- 만들 것: ...
- 입력: ...
- 출력: ...
- 적정 작동 기준: ...
```

**5 항목 본질**:
- **AX 핵심 판단**: case의 본질 결정·어디서 무엇을 어떻게 결정해야 하는가
- **만들 것**: 산출물 형태 (플러그인·룰북·매트릭스·하네스 등) + 본질 변화·작동 양식
- **입력**: LD 직접 입력 값 + 시스템 조회 데이터 (분리 표기)
- **출력**: 정보화 후 최종 형태·raw 입력 대비 변화 가시화
- **적정 작동 기준**: 1차 합격선·기능 작동 영역 한정 (정확도·검증 측정 X)

**세션 담당자 활용 흐름**:
1. 5 항목 읽고 *진입 직전 합의* 양식 박힘
2. 세션 대상자와 함께 *(LD 확인 필요)* 영역 채움
3. 클로드코드로 진입해 *지금 할 일* 1~3번 본격 진행

### 3-3. 주의사항 영역

- **오분류 위험**: 지금 분류·액션 잘못 적용 시 위험
- **헷갈리는 패턴 분리**: 비슷한 다른 패턴과 차별 잣대
- **다음 단계 진입 전 점검 조건**: 무엇이 정합되어야 다음 단계 진입
- **case 본질 추가 주의**: case 특유의 위험

## 4. 회고 안내 흐름

### 4-1. 세션 후 회고 입력

SKILL이 4 질문 박음·자유 본문으로 답변:

1. 추천한 영역·패턴이 세션 대상자에게 정합했는가?
2. 잘못 적용된 영역이나 패턴이 있었는가?
3. 같이 진행된 다른 영역·패턴이 있었는가?
4. SKILL 정정 영역을 발견했는가?

질문 어휘는 case별 변형 가능·답변은 자유 본문·Y/N 강제 X.

### 4-2. 자동 저장 흐름

1. SKILL이 메타 영역 (세션 일자·세션 대상자 직무·case 본문 핵심·추천 분류 결과) 자동 추출
2. 개인정보 (실명·실 회사명) 자동 가명 시도 (예: *김민선* → *LD A*)
3. 저장 직전 본문 노출·세션 담당자 컨펌 후 박힘
4. file write 실패 시 본문 출력·세션 담당자가 직접 `feedback/sessions_YYYYMM.md`에 복사

### 4-3. 저장 위치

```
~/.claude/commands/세션스킬-plugin/skills/세션스킬/feedback/sessions_YYYYMM.md
```

월별 1 파일·세션별 entry 자동 누적. git push 가능 (개인정보 가명 처리 후).

---

## 5. 압축 출력·후속 대화

### 5-1. 압축 출력 양식

압축 출력 필요 시 다음 어휘 박음:
```
/세션스킬
... case 본문 ...
+ "압축" 또는 "슬랙용"
```

→ 5섹션 → 12줄 내외 압축 출력 박힘

### 5-2. 후속 대화 양식

분류 결과 출력 후 세션 담당자가 자연어로 추가 질문 박을 수 있음:
- *영역 6이 뭐야*
- *패턴 14 좀 자세히*
- *왜 3-3이야*
- *Golden Case가 뭐야*

SKILL이 본문 영역 (SKILL.md·patterns·빠른 색인·작성 기준)에서 답변. 추정·창작 X·본문 외 영역은 *확인 질문* 양식 박힘.

---

## 6. 직무별 입력 잣대

세션스킬은 AX팀 4 직무 모두 작동:

| 직무 | 어휘 양식 |
|---|---|
| LD (교육기획) | *LD가 ...* |
| OM (교육운영) | *OM이 ...* |
| B2B 영업 | *B2B 영업 담당자가 ...* |
| 마케팅 | *마케팅 담당자가 ...* |

case 본문에 직무 명시 있으면 그 어휘 박힘·명시 X면 *세션 대상자* 단독 어휘 박힘.

## 7. 자주 보는 질문

### Q1. 답변 분류가 잘못된 것 같은데 어떻게 정정?
→ 회고 안내 Q2 영역에 *어느 영역·패턴이 잘못 적용됐는지* 자유 본문으로 박음. 누적 데이터 N건 후 사용자·팀원 취합·SKILL 정정 진입.

### Q2. case 본문이 너무 짧거나 정보 부족하면?
→ SKILL이 Fallback A (입력 부족) 양식 박음·*어느 영역 채우면 어느 단계 판단 가능*한지 출력. 보강 후 재실행.

### Q3. 세션 대상자가 새로운 직무 (예: 디자인)면?
→ case 본문에 직무 명시 박힘·SKILL이 직무 어휘 따라감. 다만 1차 세션 8 case·신규 4 case 영역에 없는 직무라면 매칭 정합도 낮을 수 있음·회고 안내 Q4에 박음.

### Q4. 결과를 LD에게 그대로 보여줘도 되나?
→ 가능·다만 *세션 담당자가 읽고 핵심 발췌해서 설명*하는 양식이 더 자연. 5섹션 본문이 *세션 담당자 인지용*·*LD에게 핵심만 전달* 흐름.
