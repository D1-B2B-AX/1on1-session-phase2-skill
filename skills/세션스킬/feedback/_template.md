## 작성 원칙

- **자유 본문 양식** — Y/N 강제 X·자유 양식·case별 변형 OK
- **개인정보 가명 처리** — 실명·실 회사명은 가명 (예: *김민선* → *LD A*·*XX기업* → *고객사 X*)
- **자동 가명 실패 영역** — *(가명 처리 필요)* 표기 박힘·세션 담당자 최종 확인
- **자동 저장 실패 시** — SKILL이 본 양식 본문 출력·세션 담당자가 직접 `sessions_YYYYMM.md`에 복사
- **취합·정정 (2단계·5/26+)** — N건 누적 후 사용자·팀원 취합·정정 후보 추출·사용자 컨펌·SKILL.md 정정·push
