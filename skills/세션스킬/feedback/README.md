# feedback — 회고 답변 누적 폴더

## 본질

세션스킬 SKILL 실행 후 회고 답변 자동 저장 폴더. 운영 데이터 누적·N주 후 사용자·팀원 취합·SKILL.md 정정 후보 추출 본질.

## 폴더 구조

```
feedback/
├── README.md          # 본 파일
├── _template.md       # 세션별 entry 양식 templates
└── sessions_YYYYMM.md # 월별 1 파일·세션 entry 자동 누적
```

## 자동 저장 흐름

1. SKILL이 회고 답변 받음 (4 질문 자유 본문)
2. 메타 영역 (세션 일자·세션 대상자 직무·case 본문 핵심·추천 분류 결과) 자동 추출
3. 개인정보 (실명·실 회사명) 자동 가명 시도
4. 저장 직전 본문 노출·세션 담당자 컨펌
5. `sessions_YYYYMM.md` 월별 파일에 자동 entry 박힘
6. file write 실패 시 본문 출력·세션 담당자 수동 복사

## 취합·정정 (2단계·5/26+ 영역)

- 운영 기간 N주 후 사용자 (정현) 또는 팀원이 누적 데이터 검토
- 정정 후보 추출 — 어느 영역·패턴 정정할지 사람 판단
- 사용자 컨펌·SKILL.md 정정·push (작성 원칙 19·20번 Golden Case 회귀·답지 vs SKILL 차이 5 분류 잣대 정합)
- 자동 학습·자동 반영 X — 오학습·과적합 위험 회피

## 관련 영역

- SKILL.md §4 *5. 회고 안내* — 회고 질문 + 자동 저장 흐름
- SKILL.md §5 작성 원칙 28번 — 회고 수집·저장 양식 잣대
- `_template.md` — 세션별 entry 양식
