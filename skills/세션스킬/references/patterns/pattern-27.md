## 패턴 27. LLM 자기 평가

> **영역**: 10. Validation 분기 · **빈도**: ★★ · **출처**: DeepEval / arXiv 2506.13023 (260520 추가)

### 기본 분류
- 영역: 10. Validation 분기
- 패턴: 27. LLM 자기 평가
- 실행 양식: AI 평가자 기반 검증 설계

### 한 줄 기준

사람이 모든 산출물을 전수 검수하기 어렵고, 평가 기준을 rubric·PASS/FAIL 기준으로 명시할 수 있어 LLM을 보조 평가자로 써야 할 때 적용한다.

### 적용 신호

- AI 산출물이 많아 사람이 전수 검토하기 어렵다.
- 없는 내용 생성·질문 적합성·근거 충실도·관련성 같은 평가 기준을 문장으로 정의할 수 있다.
- 사람 판정 일부 또는 Golden Case와 비교해 평가자 LLM의 판정 품질을 확인할 수 있다.
- 반복 운영에서 검토 우선순위나 1차 PASS/FAIL 라벨이 필요하다.
- 산출물 자체 생성 LLM과 별도의 평가 프롬프트·평가 모델·평가 rubric을 둘 수 있다.

### 비적용 신호

- 평가 기준이 사람 취향·정치적 맥락·한국어 뉘앙스에 크게 의존하고 rubric으로 고정하기 어렵다.
- 사람 판정 샘플이나 Golden Case가 없어 평가자 LLM이 맞는지 비교할 수 없다.
- 최종 승인·고객 발송·법적 판단처럼 AI 판정을 그대로 확정값으로 쓰면 위험하다.
- 평가자 LLM과 피평가자 LLM이 같은 종류의 실수를 할 가능성이 큰데 교차 검증 장치가 없다.
- 산출물 수가 적어 사람이 직접 보는 편이 더 빠르고 안전하다.

### 필요한 입력값

- 평가 대상 산출물 / 평가 rubric / PASS·FAIL 또는 점수 기준 / 사람 판정 샘플 / Golden Case / 평가자 LLM 프롬프트 / 불일치 처리 기준

### 판단 기준

- 검증 대상은 패턴 21(검증 양식 4 갈래)로 먼저 정한다.
- LLM 자기 평가는 *무엇을 검증할지*가 아니라 *누가 판정할지*를 정하는 패턴이다.
- 평가 기준이 문장 rubric으로 명시되고, 사람 판정이나 Golden Case와 대조 가능해야 한다.
- 평가자 LLM은 최종 판정자가 아니라 검토 우선순위와 반복 운영 비용 절감용 보조 판정자다.

### 추천 액션

- 실행 시점: 검증 대상과 성공 기준은 정해졌지만 사람 전수 검수가 부담이 되는 때
- 실행 주체: 세션 담당자와 LD
- 액션 내용: 평가 rubric을 작성하고, 평가자 LLM 프롬프트·점수 기준·PASS/FAIL 기준·사람 재검토 조건을 정함. 최소 샘플에서 사람 판정과 LLM 판정을 비교하고 불일치 유형을 기록
- 완료 기준: 평가 rubric·judge 프롬프트·샘플 대조 결과·사람 재검토 조건·최종 사용 범위가 정리된다

### 주의사항

- 오분류 위험: LLM 판정을 독립 검증이나 최종 승인처럼 오해하면 위험
- 헷갈리는 패턴: 검증 양식 4 갈래(패턴 21) — 21은 검증 대상·범위 선택, LLM 자기 평가는 판정 주체 선택. Golden Case 검증(패턴 11) — Golden Case는 기준 사례 검증, LLM 자기 평가는 그 기준을 평가자 LLM이 적용하게 하는 방식
- 쓰면 안 되는 조건: 사람 판정 샘플 없이 평가자 LLM을 바로 신뢰하는 경우
- 추가 주의: self-preference·verbosity 편향, 같은 모델 계열의 공통 오류, 한국어 B2B 교육 도메인 신뢰도 미검증 가능성

### 대표 사례

- 1차 8 case 직접 적용 사례 없음
- 예상 적용: 만족도 자유응답 분류나 자막 교정 결과가 대량으로 쌓여 사람이 전수 확인하기 어려울 때, 사람 판정 샘플과 대조한 뒤 LLM 자기 평가를 1차 검토 우선순위 산정에 사용

### 정보 부족 시 확인 질문

- 평가할 산출물은 무엇인가요?
- PASS/FAIL 또는 점수 rubric을 문장으로 정의할 수 있나요?
- 사람 판정 샘플이나 Golden Case가 있나요?
- LLM 판정이 틀렸을 때 사람이 다시 볼 조건은 무엇인가요?
- 평가자 LLM을 최종 승인자로 쓰려는 건가요, 검토 우선순위 산정에 쓰려는 건가요?
