## 패턴 23. 이해관계자별 액션 분배

> **영역**: 12. 수신자별 액션 카드 · **빈도**: ★ · **흡수**: #25 다중 수신자 액션 카드

### 기본 분류
- 영역: 12. 수신자별 액션 카드
- 패턴: 23. 이해관계자별 액션 분배
- 실행 양식: 수신자별 액션 카드 작성

### 한 줄 기준

분석 결과가 내부 인사이트에서 끝나지 않고, 수신자별 행동 요청으로 이어져야 할 때 적용한다.

### 적용 신호

- 보고서가 "그래서 뭘 해야 하지?"에서 멈춘다.
- 강사·교육담당자·운영자·의사결정자가 서로 다른 액션을 해야 한다.
- 분석 도구가 실무 의사결정으로 이어져야 한다.
- 원문 근거를 바탕으로 요청 문장을 만들 수 있다.

### 비적용 신호

- 수신자가 하나뿐이거나 모두 같은 행동을 하면 된다.
- 분석 결과를 행동 요청으로 연결할 필요가 없다.
- 원문 근거 없이 액션 카드만 만들려는 상황이다.
- 수신자가 실제로 누구인지 정해지지 않았다.

### 필요한 입력값

- 분석 결과 / 수신자 유형 / 각 수신자가 해야 할 행동 / 원문 근거 / 후속 액션

### 판단 기준

- 보고서가 "그래서 뭘 해야 하지?"에서 멈춘다.
- 수신자별로 서로 다른 액션이 필요하다.
- 분석 도구가 실무 의사결정으로 이어져야 한다.
- 원문 없는 액션 카드는 LLM의 지어내기가 될 수 있다.

### 추천 액션

- 실행 시점: 분석 결과를 실제 요청·의사결정으로 바꿔야 할 때
- 실행 주체: 세션 담당자 또는 LD
- 액션 내용: 수신자 유형 먼저 정함·각 수신자별 요청 문장·원문 근거·후속 액션을 카드로 작성. 원문 없는 액션은 제외하거나 확인 질문으로 넘김
- 완료 기준: 수신자별 카드에 요청 문장·근거 원문·후속 액션 모두 포함

### 주의사항

- 오분류 위험: 원문 없는 액션 카드는 LLM의 지어내기
- 헷갈리는 패턴: 결정론 계산 코드화(패턴 7) — 액션 카드는 수치 계산보다 결과를 누구에게 어떻게 요청할지 나누는 문제
- 쓰면 안 되는 조건: 수신자가 실제로 누구인지 정하지 않은 상태

### 대표 사례

- 안유진B: 만족도 분석 결과에 강사용 카드와 교육담당자용 카드 추가. 강사에게 요청할 것과 내부 의사결정자에게 공유할 것 분리

### 정보 부족 시 확인 질문

- 이 분석 결과를 받아야 하는 사람들은 누구인가요?
- 수신자별로 해야 할 행동이 서로 다른가요?
- 각 요청 문장을 뒷받침하는 원문 근거가 있나요?
- 수신자가 실제로 다음에 해야 할 후속 액션은 무엇인가요?
- 원문 근거 없이 만들어진 액션이 섞여 있나요?
