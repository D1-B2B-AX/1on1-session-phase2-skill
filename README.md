# 세션스킬 플러그인 (1:1 AX 세션 형식지 분류 SKILL)

> **본질**: AX팀 1:1 세션에서 세션 대상자 case를 *영역 15·패턴 30·실행 양식·현재 단계*로 1차 분류하고·*분류 근거·실행 설계 요약·다음 액션·주의사항·회고 안내* 5섹션으로 출력
> **대상**: 세션 담당자 (비전문가 대상·세션 전·중 빠른 분류 진단 본질)
> **양식**: 단일 SKILL 본질·플러그인은 배포·자동 update 포장

---

## 1. 설치

```bash
cd ~/.claude/commands
git clone https://github.com/D1-B2B-AX/1on1-session-phase2-skill.git 세션스킬-plugin
```

설치 후 Claude Code 새 세션 진입 시 `/세션스킬` 트리거 작동.

## 2. 진입 방법

Claude Code 새 세션에서 다음 트리거 박음:

```
/세션스킬
```

→ SKILL이 4 영역 입력 안내 박힘 (업무 유형·현재 해결 방식·시도한 도구·결과물·세션 대상자 발화)
→ 자유 양식으로 case 본문 박음
→ SKILL이 5섹션 분류 결과 출력 (분류·근거·다음 액션·주의사항·회고 안내)

## 3. 자동 update

매 트리거 시점에 SKILL이 자체 `git pull --quiet` 실행 (네트워크 오류 시 무시·진행 계속). 차후 정정·신규 영역은 자동 흡수.

수동 update:
```bash
cd ~/.claude/commands/세션스킬-plugin && git pull
```

## 4. 폴더 구조

```
세션스킬-plugin/
├── README.md                          ← 본 파일·설치·진입 가이드
├── docs/
│   ├── 세션스킬_사용자_가이드.md      ← 세션 담당자 상세 사용 가이드
│   └── 세션스킬_학습자료.md           ← Cheat sheet (15 영역·30 패턴 본질)
└── skills/
    └── 세션스킬/
        ├── SKILL.md                   ← SKILL 본문 (LLM 호출 지침서)
        ├── references/                ← 영역·패턴·작성 기준 참조
        │   ├── 패턴_빠른_색인.md
        │   ├── 세션스킬_출력_내부_사전_실행_양식_작성_기준.md
        │   └── patterns/pattern-01.md ~ pattern-30.md
        └── feedback/                  ← 세션 후 회고 답변 월별 자동 누적
            ├── _template.md
            ├── README.md
            └── sessions_YYYYMM.md
```

## 5. 가이드 자료

| 자료 | 본질 | 대상 |
|---|---|---|
| `README.md` (본 파일) | 설치·진입·자동 update | 설치자 (입구) |
| `docs/세션스킬_사용자_가이드.md` | 4 직무 (LD·OM·B2B 영업·마케팅) 입력 양식·5 항목 sub-block 본질·회고 안내 흐름 | 세션 담당자 (사용) |
| `docs/세션스킬_학습자료.md` | 15 영역·30 패턴 본질·압축·쉽게·비유 3 양식 | 세션 담당자 (학습) |

## 6. 회고 답변 자동 저장

세션 후 회고 안내 4 질문에 자유 본문으로 답변하면 SKILL이 `feedback/sessions_YYYYMM.md` 월별 파일에 자동 누적 저장. 개인정보 (실명·실 회사명)는 자동 가명 처리 시도·저장 직전 본문 컨펌 박힘.

차후 사용자·팀원이 누적 데이터 취합·정정 후보 추출·SKILL 정정·push 흐름.
